# Exploratory Data Analysis (EDA) & Sales Analytics

A comprehensive data analytics project focused on cleaning, exploring, and visualizing core sales performance metrics using Python.

## 🛠️ Tech Stack
- **Language:** Python
- **Environment:** Jupyter Notebook (`.ipynb`)
- **Key Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 📈 Analysis Workflow
1. **Data Cleaning:** Handled missing data entries, normalized column data types, and filtered outliers.
2. **Descriptive Statistics:** Calculated overall revenue metrics, monthly growth trends, and high-performing store segments.
3. **Data Visualization:** Built correlation heatmaps, distribution plots, and time-series line graphs using Seaborn to spot purchase behavioral patterns.
